# 기수별 이모저모 상세 모달 개선 — 2026-10-22

기존 PC 세로 모달을 사진·본문 가로 구성으로 바꾸고, 모바일의 사진 표시와 게시물 이동 UI를 정리했다. 수정은 저장소 원본 CSS·JS와 페이지 템플릿에 반영하고 HTML을 빌드했다.

## 최종 동작

- PC는 왼쪽 사진·오른쪽 계정/본문/하단 액션 구조다. 화면 여백을 남기며 사진 캔버스는 대표 사진 기준 4:5~1:1 범위로 정한다. 가로 사진은 검은 배경에 `contain`으로 표시하고, 같은 게시물의 사진을 넘겨도 모달 크기를 유지한다.
- PC의 긴 본문은 후기 상세와 같은 바깥 스크롤바로 읽는다. 드래그 및 방향키·PageUp/Down·Home/End를 지원한다.
- 모바일은 바깥 스크롤바를 숨기고 본문의 기본 세로 터치 이동을 유지한다. 게시물 이동 버튼은 사진·본문 경계 높이의 카드 바깥에 두며, 긴/짧은 본문과 점 유무에 따라 높이가 바뀌지 않는다. 시각적 원 26px·흰 화살표 14px, 어두운 반투명 배경, 터치 영역 44px이다.
- 모바일 사진 넘김은 기존 좌우 스와이프와 사진 아래 흰 영역의 파란/회색 점을 사용한다. 사진 오른쪽 위에는 `현재/전체` 배지를 표시한다. PC는 사진 안쪽의 흰색 점과 사진 이동 화살표를 유지한다.
- 상세 점은 사진 개수만큼 생성한다(기존 최대 10장 정책 유지). 날짜는 PC·모바일 모두 상단 아이디 옆으로 옮긴다. 제목 아래 여백은 PC 28px·모바일 24px이다. 모바일 전체보기는 작은 14px 아이콘과 44px 터치 영역을 사용한다.

## 검증

- `npm run build`, `npm test` 163개, `npm run check:public`, `git diff --check` 통과. 미리보기 서버 실행 확인.
- PC 1280/1440px와 모바일 360/390/430px에서 모달·가로 넘침·날짜·버튼 위치·사진 표시를 확인했다.
- 게시물 이전/다음, 사진 점 선택과 개수 연동, 사진 확대/복귀, Escape 닫기 확인. PC 외부 스크롤바 드래그 및 Home/End 확인.
- 로컬에만 긴 문단 18개를 임시 주입해 PC 본문 끝까지 이동, 모바일 본문 이동과 스크롤바 숨김, 긴/짧은 게시물의 버튼 높이가 같은지 확인했다. 이 임시 문단과 서버 스크립트는 저장소/PR/DB에 포함하지 않는다.
- 실제 휴대전화 터치 조작과 통합 V30 서버 재배포 후 확인은 별도 검증 대상이다. 브라우저에서는 기존 스와이프 핸들러·`touch-action:pan-y` 및 본문 이동을 확인했다.

## 연동 경계

V30의 사본 → 공개 API → 렌더러 흐름과 `cv3-data`·`st-*`·선택자를 유지한다. 본문/대표 이미지/사진 목록은 기존 렌더러가 만든 마크업에서 읽는다. API·관리자·DB·데이터 사본은 변경하지 않았으며, 통합본 자동 동기화나 배포는 수행하지 않았다. 과거 Spring 내보내기는 현재 연동 경로가 아니므로 이번 PR에서는 실행/생성하지 않았다.

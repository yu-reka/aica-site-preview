서체와 크기 역할

Giants는 큰 표제와 기존 번호, Paperlogy는 콘텐츠 제목과 승인된 본문, Pretendard는 공통 메뉴·푸터·모바일 본문을 담당합니다. 공통 caption 12px, control label 14px, 기본 본문 참조 16px, section 참조 clamp(28px,2.8vw,38px)를 토큰에 기록합니다. 모바일 본문 14px와 FAQ 배지 12.5px 등 페이지별 예외는 유지합니다. 크기를 전역 강제하지 않으며 기존 라벨 토큰을 실제 공통 컨트롤에 연결합니다.

경계 너비와 레이어

600px: 본문·하단 이동 컨트롤. 1080px: 공통 모바일 메뉴. 1200px: 좌측 내비게이션. 경계 양쪽의 600/601, 1080/1081, 1199/1200과 320px·1280px를 검증합니다.

헤더 50, 하단 이동 45(체크 35 유지), 메뉴 딤 59, 드로어 60, 토스트 90, 후기/사진 모달 200, 사진 확대 260을 공통 토큰으로 매핑합니다. 지역 스태킹 컨텍스트는 유지합니다.

소유 파일과 갱신

tokens.css는 브랜드·역할 토큰, components.css는 공통 컨트롤, ui.js는 초점·배경 격리·유한 레일 계약을 담당합니다. 페이지 CSS는 본문·사진·여백·기능별 변형을 소유합니다. ui.js는 소비자보다 먼저, components.css는 페이지 모바일 CSS 뒤 및 navigation-mobile.css 앞에 로드합니다.

토큰이 바뀌면 다운로드와 source-manifest를 함께 다시 생성합니다. 이 다운로드 CSS는 참조용이며 원본 위에 추가로 덮어씌우는 파일이 아닙니다. 외부 배포 시 폰트 라이선스와 상대 경로를 유지합니다.

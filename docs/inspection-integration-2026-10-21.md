## Spring 영향과 미검증 항목

새 `ui.js`, `components.css`가 추가되므로 운영 Spring에 반영할 때 템플릿과 정적 자산을 함께 갱신해야 합니다. 후기 태그 부분 템플릿의 내부 구조는 통합했지만 공개 데이터·임시저장·발행 정책·API 계약과 관리자 권한은 변경하지 않았습니다. 별도 백오피스 저장소와 운영 DB에는 쓰지 않았습니다.

실제 Spring 서버 및 운영 DB의 모든 레코드 조합, 스크린리더 낭독, iOS/Android 물리 기기와 OS 모션 설정 전환은 미검증입니다. 화면·런타임 테스트 결과를 전체 WCAG 인증으로 해석하지 않습니다.

## 시설 모바일 사진 순환 추가

시설 사진의 양쪽 화살표를 항상 활성화했습니다. 첫 사진에서 이전을 누르면 마지막 사진으로, 마지막 사진에서 다음을 누르면 첫 사진으로 순환합니다. 사진 캡션·현재 번호와 동작 줄이기 설정은 유지하고, 시설 사진 외의 카드 레일과 데스크톱 갤러리는 변경하지 않았습니다.

360·390·430px의 프로젝트 공간(3장)에서 양방향 순환과 두 버튼 활성 상태를 확인했고, 구내식당(2장)에서도 순환과 Enter 조작을 확인했습니다. 1440px 가로 넘침은 없으며 자동 테스트 71개, build/check도 통과했습니다.

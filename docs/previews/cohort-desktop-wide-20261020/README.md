# PC 기수 기록 상세 카드 비율 조정

PC(761px 이상)에서 세로 카드 구성을 유지하면서 최대 폭을 420px에서 520px로 넓히고 사진 비율을 1:1에서 4:3으로 변경했습니다. 화면 높이에 따른 폭 제한과 내부 스크롤은 유지합니다. 모바일 스타일은 변경하지 않았습니다.

- [PC 다중 사진](desktop-after.png)
- [PC 단일 사진](desktop-single-photo.png)
- [모바일 390px](mobile-390.png)

로컬 서버 4173에서 PC 및 모바일 360·390·430px를 확인했습니다. PC 사진 넘김과 닫기, 모바일 정사각 비율 및 가로 넘침 없음을 확인했습니다.

검증: build 11개 생성, test 61개 통과, check 11개 일치. 최신 origin/main(6fcf20b)을 반영했습니다.

Spring API·데이터·마크업 변경 없이 공용 스타일만 조정했습니다. Spring 내보내기 관련 자동 테스트는 통과했으며 실제 Spring 서버 실행은 수행하지 않았습니다.

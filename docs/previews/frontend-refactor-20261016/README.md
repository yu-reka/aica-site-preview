## Spring 확인 범위

별도 임시 출력·H2 메모리 DB·격리 Spring 서버에서 새 후기 템플릿의 전용 스크립트 → 공통 진입점 순서와 10개 목록·상세창을 확인했습니다. 새 공통 CSS·후기 JS·라이프 뷰 JS는 HTTP 200으로 서빙됩니다.

임시 템플릿에서 후기 전용 스크립트 태그를 제거하고 이전 mast CSS URL로 바꾼 호환 fixture도 확인했습니다. 공통 진입점의 동적 로더로 목록·2페이지·상세창이 동작했고 콘솔 오류가 없었습니다. fixture를 원복하고 검증 서버를 종료했습니다.

실제 백오피스 저장소·실제 DB·운영 배포는 변경하지 않았습니다. 작업본 발행의 DB 쓰기 왕복은 이번 검증 범위가 아니며, 본문·seed·live 계약 보존과 격리 DB의 공개 화면 읽기를 확인했습니다. 기존 서버를 중단하지 않았습니다. 마무리 시 4173 서버가 꺼져 있어 `npm run preview`로 다시 실행하고 새 파일을 참조하는 라이프 화면의 HTTP 200과 실제 렌더링을 확인했습니다.

## 후속 오류 수정·통합 검증

기수 기록 상세창의 Tab 포커스 이탈과 잘못 인코딩된 해시로 인한 Check·Stories 초기화 중단을 수정했습니다. 상세·확대창의 배경 격리와 복원, 비활성화된 이전·다음 버튼의 포커스 경계까지 확인했습니다. 초기화 전에 실행되는 옛 주소 라우터도 예외를 처리합니다. 원본 스크립트 URL 버전과 생성물을 함께 갱신했습니다.

- 자동 테스트 32개 통과. 새 회귀 테스트 6개는 수정 전 main에서 모두 실패하고 수정 후 통과합니다.
- 최종 코드로 360·390·430·1280·1440px의 60개 렌더링 조건을 다시 비교했으며 본문·배치·색·폰트가 같고 가로 넘침이 없습니다. [최종 화면 비교](final-visual-parity.json)
- 두 오류와 중첩 확대창·배경 복원·비활성 버튼 경계의 브라우저 검사 47개 통과. [기능 회귀 검사](final-fixed-flows.json)
- 최신 내보내기로 격리 Spring/H2의 5개 이야기 페이지·4개 공개 API·신규 자산 HTTP 200, 모바일·데스크톱의 수정 기능과 이전 템플릿 동적 로더까지 11개 브라우저 조건 통과. [Spring 화면 검사](final-spring-flows.json)
- 실제 운영 DB의 저장·발행 왕복은 재실행하지 않았습니다. 공개 컨트롤러의 발행본 읽기 경계와 내보내기 본문·seed 보존을 확인했습니다. 실제 백오피스 저장소·DB는 변경하지 않았습니다.

# 모바일 랜딩 태그 및 체크 카드

- 2번 `#비전공자도 #팀으로`, 3번 `#프로젝트도 #열심히`를 사진 하단 한 줄로 묶고 반투명 검정 배경과 흰 글자로 표시합니다.
- 1번 `#정문` 흰 스티커를 유지하고 지도 주소 스티커를 오른쪽 아래로 옮겼습니다.
- 손글씨·화살표 크기와 위치를 조정하고 초록 체크 카드에 기울기·그림자·제목 구분선을 적용했습니다.
- 데스크톱은 태그 그룹에 display:contents를 적용해 기존 그리드 배치를 유지합니다.
- 스타일 URL 버전을 갱신했습니다. 캐시가 과거 화면 차이의 유일한 원인이라고 확정하지는 않았습니다.

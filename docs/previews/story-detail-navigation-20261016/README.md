# 공통 상세 탐색: 간결한 좌우 링크형

최신 origin/main cc1d10b 기준, codex/story-detail-navigation 브랜치의 로컬 원본에 적용했습니다. 랜딩 PR #13과 분리한 작업입니다. 아직 PR 생성·main 병합·배포는 하지 않았습니다.

후기 모달·인터뷰·프로젝트의 본문 끝에 이전/다음 제목과 목록 복귀 링크를 통일했습니다. 인터뷰·프로젝트는 부가 정보 다음에 배치합니다. 기존 프로젝트 사이드 탐색은 공통 탐색이 준비되면 숨기며, 레거시 원본 슬롯은 Spring 템플릿 호환을 위해 유지합니다.

페이지에 이미 렌더링된 공개 카드와 상세 제목을 읽어 탐색을 만들고, 텍스트는 textContent로 삽입합니다. 정적 자료와 Spring 발행본 모두 같은 경로를 사용합니다. 첫/마지막 글에서는 이동할 수 없는 방향을 링크가 아닌 비활성 안내로 표시합니다. 후기 카테고리·기수·태그, 인터뷰 기수 선택에 맞는 카드 순서로 이동합니다. 목록 복귀 시 필터 상태와 원래 스크롤 위치를 보존합니다.

## 확인 범위

Spring 실행 환경은 구동하지 않았으며 내보내기 템플릿과 자산 경로만 테스트했습니다. 다른 저장소·DB에는 내보내지 않았습니다. 기존 해시·선택자·RichText 검증·모션 감소 규칙은 유지합니다. 실제 터치 기기의 스크린리더와 모션 감소 설정은 추가 확인 대상입니다.

## 후기 모달 하단 끝맞춤 추가 수정

공통 탐색이 있는 모달에만 기존 스크롤 영역의 padding-bottom:28px를 제거했습니다. 흰 탐색 영역이 모달 끝에 닿고 종이 모서리 효과는 유지됩니다. PC 1440px, 모바일 360·390·430px에서 탐색 뒤 남는 스크롤 영역이 0px이며 가로 넘침이 없음을 확인했습니다. build/test(33개)/check 성공.

## 모바일 프로젝트 카드 대표 이미지 추가

모바일 아코디언 카드의 소개 문장·요약·태그·팀 정보 대신 해당 프로젝트의 기존 대표 이미지(SVG 또는 실제 업로드 이미지)를 재사용합니다. 번호·유형·제목·상세보기는 유지합니다. 원본 콘텐츠와 PC 카드는 변경하지 않습니다. Spring 발행 카드의 이미지도 같은 DOM 경로로 재사용합니다.

360·390·430px에서 이미지 6개 생성, 제거 대상 요소 0개, 가로 넘침 없음을 확인했습니다. 기업연계 필터에서 3개 표시와 첫 카드 펼침, 상세보기 #pj-2 이동을 확인했습니다. PC 1440px에서는 기존 카드 그리드와 설명 6개가 유지됩니다. build/test(33개)/check 성공.

## 모바일 이미지 카드 균형 보정

상세보기 버튼을 내용 폭(약 149px)의 작은 외곽선 버튼으로 줄이고 이미지와 18px 간격을 뒀습니다. 이미지와 버튼을 카드 전체 폭의 중앙에 맞췄습니다. 360·390·430px에서 둘 다 카드 중심과의 오차 0px, 가로 넘침 없음을 확인했습니다. 터치 높이 44px를 유지합니다. 프로젝트 페이지 모바일 CSS 캐시 버전도 갱신했습니다. build/test(33개)/check 성공.

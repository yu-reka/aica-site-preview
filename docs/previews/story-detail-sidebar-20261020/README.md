# 프로젝트 상세 정보·고정 카드 경계 수정

기준: PR #15 병합 후 `origin/main` d87b4ac. 브랜치: codex/story-detail-sidebar-fix.

## 변경

- 정적 프로젝트 상세 대표 이미지 배지를 기존 유형에서 과정명으로 변경하고, 정보 카드의 유형을 과정으로 변경했다. 목록 드롭다운·빈 결과·접근성 이름의 교과목 문구도 과정으로 통일했다.
- 기간 대신 기수·반을 표시한다. 기존 팀 정보에서 확인되는 반 번호만 사용한다. 반 정보가 없는 틈·파수는 기수만 표시한다. 데이터의 `cohortClass`는 정적 시안용이다. 제목·설명·태그도 기존 시안 데이터로 유지했다.
- PC 프로젝트 정보 카드에 이전·다음 링크를 복원했다. 현재 기수·과정 필터를 따르고 양끝에서는 더 이상 글이 없다는 안내를 표시한다.
- 모바일 600px 이하에서는 정보 카드 안의 이전·다음만 숨기며 하단 공통 탐색은 유지한다.
- 인터뷰·프로젝트 하단 공통 탐색을 본문/오른쪽 카드 그리드의 다음 형제로 이동했다. 오른쪽 sticky 카드의 컨테이너가 본문 끝에서 끝나므로 하단 탐색과 겹치지 않는다. 후기 모달 탐색 구조는 유지한다.
- 최신 main의 `19203cd` Spring 모바일 프로젝트 유형 필터와 테스트를 보존했다. 원격에 있던 전체 통합 브랜치를 다시 병합하지 않고 추가 수정 단일 커밋만 옮겼다.

## Spring 경계 및 미검증

PR16의 Spring DB 필터와 함께 통합했다. 과정은 공개 subject를 사용하며 비어 있으면 기존 type으로 표시한다. 기수는 공개 cohort가 있을 때 기수만 표시하며, 기존 미분류 글은 duration/기간을 유지한다. 반 번호는 Spring 저장 계약에 추가하지 않는다. 목록의 cohort/subject 메타데이터와 동적 필터를 유지한다. 공통 상세 탐색 배치와 모바일 정보 카드 링크 숨김은 내보내기 자산에도 반영된다. 발행 정책/HTML escape/API 계약은 변경하지 않았다. 최종 실제 Spring 검증은 [PR16–19 통합 검증](../pr16-19-integration-20261020/README.md)을 참고한다. 운영 DB·물리 기기·스크린리더·Windows 실행은 미검증이다.

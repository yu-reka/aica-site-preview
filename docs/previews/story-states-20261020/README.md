# 이야기 목록 공통 상태

기존 정상 목록·카드·메뉴 디자인을 유지하고 네 이야기 목록에 빈 상태/필터 결과 없음/조회 실패와 동작 버튼을 공통 적용했습니다. 빈 DB를 정적 시안 글로 대체하지 않습니다.

검증: `npm run build`, `npm test`(66개), `npm run check`. 실제 Chromium에서 네 목록 × 360/390/430/1280/1440px의 정상 main 비교 20쌍, 빈/오류 상태 40건을 확인했습니다. 캡처는 브라우저 fixture로 빈 서버 마크업과 `publicContentUnavailable` 플래그를 재현한 화면입니다. 서버 컨트롤러의 실제 HTTP 503 처리는 비공개 통합 저장소의 별도 백엔드 PR과 연결합니다.

확인한 동작: 기수 기록 영상/월 필터 0건·초기화·모바일 탭 동기화, 후기 모바일 교차 필터 0건·초기화, 정적 후기 마지막 페이지 초기화 후 화살표, 프로젝트 7기 준비 중 시안 유지·6기 복귀, 조회 재시도 후 정상 복구, `/aica-site-preview/` 링크·자산. 브라우저 JS 오류 0건.

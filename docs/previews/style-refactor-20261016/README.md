## 빌드·연동

- `npm run build`: 11개 파일 생성.
- `npm test`: 15개 통과. CSS 소유 파일·링크 순서·자산 경로·Spring 링크 회귀 검사 3개 포함.
- `npm run check`: 생성물 11개 일치. `git diff --check` 통과.
- `/aica-site-preview/stories/reviews.html`에서 CSS와 이미지가 상대 경로로 로드됨. 깨진 이미지 없음.
- 기준본·작업본 Spring 내보내기의 후기/이야기 시드 JSON은 바이트 동일. 공개 템플릿 5개는 CSS 링크 교체와 주석만 변경. 비템플릿 산출물 변경 없음.
- 기존 컴파일된 Spring 애플리케이션을 새 H2 메모리 DB와 임시 출력 폴더로 실행. 공개 페이지 5개·새 공통/이야기 CSS·공개 API 4개 HTTP 200. 브라우저에서 DB 후기 목록과 상세 확인, 콘솔 오류 없음.
- 공개 컨트롤러의 `published()` 조회 경로 유지. 콘텐츠·ID·발행 정책·백오피스 코드는 변경하지 않음.

기존 로컬 DB와 실행 중인 서버는 수정하지 않았습니다. 실제 운영 DB·기관 서버 배포·백오피스에서 임시저장 후 발행하는 전체 시나리오는 이번 CSS 변경의 검증 범위에 포함하지 않았습니다.

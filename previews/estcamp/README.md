# ESTcamp × 인사교 UI 디자인 시안

2026-10-22 원본 사이트와 KDT 디자인 자산집을 확인해 만든 **독립 홈 시안**입니다. 인사교 원본 페이지, ESTcamp 운영 사이트, API·DB·Spring 파일을 수정하지 않습니다. main 병합·공개 배포는 하지 않습니다.

## 확인

저장소 루트에서 `npm run preview -- --port 4197`을 실행한 뒤 아래 주소를 엽니다.

- 시안: http://127.0.0.1:4197/previews/estcamp/
- 크기별 검토: http://127.0.0.1:4197/previews/estcamp/review.html

이 주소는 현재 컴퓨터의 로컬 미리보기입니다. 폴더만 따로 제공할 때는 이 폴더에서 `npm run preview`로 실행할 수 있습니다.

## 원본과 적용

- 콘텐츠·공고·이미지: https://estbootcamp.co.kr/ (2026-10-22 화면 기준)
- 브랜드: https://estsoft-kdt-design.netlify.app/#top (ESTcamp BI V1.0)
- UI 기준: 인사교의 홈 모듈 배치, 공통 헤더, 검은 테두리·그림자 배너, 흰 알약 CTA, 프로젝트 카드의 연회색 바탕·16:10 이미지, 배지, 이야기 배너, 지원 전 체크의 체크리스트.
- 브랜드 지정: EST Blue #0047FF, Mint #00E2E6, Black, White / Paperlogy 제목·Pretendard 본문. 민트는 면에만 사용합니다. 과정 이미지의 고유 팔레트는 원본 자산 그대로입니다.
- 모집과정 5개 → AI 챌린저스 → 인공지능사관학교 → 콘텐츠 5개 → 지원 조건 4개 및 추천 대상 3개 → 상담 → 기관 정보의 원본 구조를 유지합니다. 히어로는 인사교의 모듈형 진입 구조로 재구성했습니다.
- 첫 화면의 ‘AI로 시작하는 나의 다음’ 등은 시안용 편집 문구입니다. 수치·교육 혜택·후기·모집 조건을 새로 만들지 않았습니다.
- 원본의 AI 휴먼 마감일 `~11.30 (화)`는 그대로 보존했습니다. 날짜·요일의 정합성과 최신 모집 조건은 운영 담당자가 최종 확인해야 합니다.
- 신청·상담·인터뷰는 검증한 원본의 외부 주소로 연결됩니다. 신청 제출, 알림 등록, 상담 접수 자체를 이 시안에서 수행하지 않습니다. 과정별 상세 페이지는 원본으로 연결됩니다.
- 원본 개인정보처리방침은 사이트 내부 안내 동작이므로 이 시안에서는 원본 사이트로 안내합니다.
- 자산 출처는 `assets/sources.json`, 폰트 라이선스는 `assets/fonts/`에 있습니다. 사내 드라이브의 비공개 파일은 가져오지 않았습니다.

## 수정·빌드

- 구성·고정 문구: `src/page.html`
- 과정·콘텐츠 데이터: `src/content.json`
- 스타일·반응형: `style.css`
- 메뉴·필터·체크·이야기 넘김: `app.js`
- `index.html`은 `npm run build --prefix previews/estcamp`로 생성합니다. 생성물을 직접 수정하지 않습니다.
- `npm run check --prefix previews/estcamp`로 원본·생성 결과 일치를 확인합니다.

## 확인 결과

- 저장소 `npm run build`, `npm test` 89/89, `npm run check` 통과.
- 시안 빌드·일치 검사 및 `node --check app.js` 통과.
- 실제 인앱 브라우저에서 360·390·430·1440px 뷰포트 확인. 해당 브라우저의 세로 스크롤바 15px를 제외한 본문 clientWidth와 scrollWidth가 일치합니다.
- 모바일 메뉴 열기·Escape 닫기, 온라인 필터 3개 표시·전체 복원, 체크 1/4 및 해제, 이야기 키보드 우측 넘김 확인.
- 감소된 모션은 CSS·JS에서 시스템 설정을 따릅니다. OS 설정 변경에 따른 실제 동작 전환과 실제 터치 기기의 스와이프는 미검증입니다.
- 캡처: `evidence/desktop-1440.png`, `desktop-hero.png`, `mobile-360.png`, `mobile-390.png`, `mobile-430.png`.
- Spring/API/DB 연동은 독립 홈 시안 범위 밖입니다. 백엔드 파일·계약 변경 없음, 실제 서버·DB 연결 테스트 없음.
